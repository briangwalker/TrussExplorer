balsaPixel: Truss Explorer 1.0.0-alpha.6 (pre-release)

New
- Results on the drawing: the two books are drawn as books on the deck, the wood you need sits under the bridge as a bundle of sticks seen end-on, and the deflection, determinacy and fits verdicts are callouts on the drawing in the meaning colours; the results card shows the numbers (#399, #484).
- Undo: after every input change a short message at the bottom says what changed ('Changed h 70 → 80') with an Undo button; Ctrl+Z or Cmd+Z also undoes it while the message shows, and focus goes back where it was (#482, #487, #497).
- A theme file (.tetheme) can be opened like a bridge file and is applied for this visit after the same checks as every other file (#265, #463, #472).
- The OG (v61) look appears in the theme list after your first finished sweep or 20 minutes, with its badge (#481, #491).

Improved
- Focus rings: on the top bar the ring takes the bar's own text colour, on the lit place pill it sits inside the pill, and the Undo button's ring shows in every theme; the Members grid keeps focus through a redraw (#474, #477, #476, #497).
- Blueprint (sample) has dark controls (#458).

Fixed
- The start-up no longer shows an Undo message for a change nobody made (#502).
- Keyboard only: the lit Truss pill's ring in the Wireframe theme, the known item from alpha.5 (#477).

Behind the scenes
- A limits table and input checks, a number box and stepper piece, gallery items for sheets, dialogs and toasts, and the empty-line words in one strings table (#461, #462, #465, #479).

Known
- The top bar can overlap the Graph options in Analysis 3D at some sizes (#495); the sweep legend lines run through the drawn books at 1366 px wide (#503); Undo after opening a file can offer an older bridge's value (#501); typing a huge number of trusses can freeze the page (#500). All planned for the next alpha.

Results are unchanged: the solver was not touched.
